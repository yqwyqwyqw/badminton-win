# Windows 客户端

这是羽毛球回合分析器的 Qt6/QML Windows 客户端。当前已接入视频导入、正式回合分析、回合拼接和最终拼接视频导出。

## 当前包含

- 选择或拖入本地视频，并校验文件和格式
- 使用 Qt Multimedia 读取文件大小、时长、分辨率、帧率和编码信息
- 显示原始日期及来源，按“文件名明确时间 → 视频内嵌日期 → Windows 文件时间”回退
- 在导入页直接播放原视频，支持暂停、拖动进度和静音切换
- 生成并缓存时间轴一致的 720p 代理视频，硬件缩放失败时自动使用兼容模式
- 从界面启动可恢复的 TrackNet 分块推理，并显示真实进度和预计剩余时间
- 每识别完一个完整回合就立即加入列表，支持短片预览和单独导出
- 在正式回合页恢复已有分析进度，并可继续分析完整视频
- 按回合切换、上一回合/下一回合播放和时间线定位
- 在回合拼接页勾选回合、拖动调整顺序，并显示预计拼接时长
- 可将不需要的回合隐藏，隐藏项半透明显示且不会计入合集
- 在回合拼接页按 0.5 秒步进或直接输入值微调单回合前后边界
- 为每个回合添加不超过 80 字的简短备注，并在列表中显示备注标记
- 按选中回合的时间索引连续预览拼接顺序，不提前生成中间文件
- 单回合导出支持 720p 快速版、1080p 高画质版和原始画质版；选项按源视频分辨率动态生成，绝不向上放大
- 原始画质导出从原视频按精确时间边界重新编码，并保留可用音轨
- 在回合拼接页将当前选中、排序和时间微调结果“推送到视频导出”页，导出页显示本次快照的回合顺序与总时长
- 最终合集从原视频按时间索引一次性拼接编码，不为每个回合预先生成中间视频
- 按源文件路径、大小和修改时间隔离缓存，切换素材不会串用结果
- 顶部显示真实素材名称和导入状态
- 支持清空当前项目，以及从导入页进入回合分析页
- 左侧四步工作流导航：视频导入、回合分析、回合拼接、视频导出
- 中央视频预览和可拖动时间线
- 正式分析进度、停止和断点继续
- 回合列表显示自动拍数作为参考信息
- 适配常见 Windows 桌面尺寸的三栏布局

视频导入由 C++ `VideoImportController` 负责；代理生成、Python/TrackNet 子进程、进度文件、增量回合列表以及 FFmpeg 单回合/合集导出由 C++ `TrialAnalysisController` 管理。回合拼接页维护选择、顺序、边界和备注，点击推送后导出页接收一个稳定快照，避免导出过程中被后续界面修改影响。

## 构建要求

- CMake 3.21 或更高版本
- Qt 6.5 或更高版本，包含 `Multimedia`、`Quick` 和 `QuickControls2`
- 支持 C++20 的编译器（Windows 推荐 Visual Studio 2022）

使用 Qt 安装目录下的命令行环境运行：

```powershell
cmake -S app -B build/app -G "Visual Studio 17 2022" -A x64 `
  -DCMAKE_PREFIX_PATH="D:/Qt/6.11.2/msvc2022_64"
cmake --build build/app --config Release
$env:Path = "D:/Qt/6.11.2/msvc2022_64/bin;$env:Path"
./build/app/Release/badminton-analyzer.exe
```

也可以通过命令行直接导入一个视频：

```powershell
./build/app/Release/badminton-analyzer.exe "F:/path/to/video.mp4"
```

Qt 版本和目录需要按本机实际安装位置调整。使用 Qt Creator 时，可以直接打开 `app/CMakeLists.txt` 并选择 Qt 6.5+ Desktop Kit。

## 后续模块接入顺序

1. 项目持久化：保存回合选择、顺序和微调后的时间边界。
2. 视频导出：按选中回合一次性拼接编码，提供导出前预览、画质选择和导出后播放。
3. 缓存清理：分析完成后按项目策略清理代理视频和轨迹分块。

播放器、推理任务和导出服务应分别通过窄接口接入 QML。正式视频预览优先使用原视频或单一代理视频的时间索引，独立回合文件只在用户明确导出时生成。
