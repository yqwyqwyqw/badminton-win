# 羽毛球回合分析器

面向 Windows 的本地羽毛球视频分析工具。目标是自动识别并切分每个回合，让用户选择、排序、微调并导出精彩回合合集；自动拍数作为回合参考信息。

## 主要功能

- 导入本地羽毛球视频并显示分析进度
- 自动识别回合起止时间，分析过程中逐个提供回合预览
- 显示每回合自动拍数，辅助判断精彩回合
- 选择回合并调整最终拼接顺序
- 隐藏不需要的回合，隐藏项半透明显示
- 微调单回合前后时间边界
- 为回合添加简短特点备注
- 按回合导出短片，或组合导出成片
- 将拼接页当前方案推送到导出页，预览回合顺序和总时长后一次性导出

## 技术栈

- Windows 桌面界面：Qt 6、QML、C++20、CMake
- 羽毛球轨迹验证：TrackNet、Python、PyTorch
- 视频代理与切片：FFmpeg
- 处理原则：全部本地运行，不依赖服务器；轨迹是回合判断的主要依据

## 实现方式

```text
原视频 → 代理视频 → 分块轨迹推理 → 回合状态机
       → 增量写入回合索引与预览 → 选择/排序/边界微调 → 导出
```

分析任务采用分块落盘，便于显示真实进度、停止和断点恢复。UI 与算法通过回合数据模型衔接；拼接页按时间索引预览，推送后的导出页保存当前回合方案快照，并由 FFmpeg 从原视频一次性拼接编码。
