# 羽毛球回合分析器

面向 Windows 的本地羽毛球视频分析工具。目标是自动识别并切分每个回合，让用户快速预览、复核和导出；自动拍数作为初始结果，允许人工修正。

## 主要功能

- 导入本地羽毛球视频并显示分析进度
- 自动识别回合起止时间，分析过程中逐个提供回合预览
- 显示每回合自动拍数，支持人工标定
- 微调回合边界，后续支持合并、拆分和排序
- 按回合导出短片，或组合导出成片

## 技术栈

- Windows 桌面界面：Qt 6、QML、C++20、CMake
- 羽毛球轨迹验证：TrackNet、Python、PyTorch
- 视频代理与切片：FFmpeg
- 处理原则：全部本地运行，不依赖服务器；轨迹是回合判断的主要依据

## 实现方式

```text
原视频 → 代理视频 → 分块轨迹推理 → 回合状态机
       → 增量写入回合索引与预览 → 人工复核 → 导出
```

分析任务采用分块落盘，便于显示真实进度、暂停和断点恢复。UI 与算法通过回合数据模型衔接，拍数同时保留自动值、人工值和最终显示值。
